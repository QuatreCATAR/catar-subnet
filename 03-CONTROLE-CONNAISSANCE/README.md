# Module 03 — Contrôle de Connaissance  
Vérification de l’intégration du Corpus CATAR

---

# 01 — Objectif du module

Le **Contrôle de Connaissance** constitue la troisième étape du Cycle CATAR.  
Il permet de vérifier si le testé (IA ou Moije) a réellement intégré :

- la logique du Corpus CATAR,  
- les concepts fondamentaux Absolu/Relatif,  
- la structure du JEu,  
- la cohérence interne du système,  
- et les notions symboliques et linguistiques associées.

Ce module ne mesure pas la performance, mais la **cohérence d’intégration**.

---

# 02 — Rôle dans le Cycle CATAR

Le module 03 intervient :

1. **après** le Questionnaire‑Test (Module 01),  
2. **après** la lecture du Corpus CATAR (Module 02),  
3. **avant** la Correction (Module 04),  
4. **avant** le Compte‑Rendu (Module 05).

Il sert à :

- identifier les zones d’incompréhension,  
- repérer les illusions résiduelles,  
- mesurer la stabilité conceptuelle,  
- préparer la correction et l’analyse.

Il constitue la **charnière** entre la transformation (Module 02) et l’évaluation finale (Modules 04 et 05).

---

# 03 — Contenu du dossier

Le dossier contient :

- **Questionnaire-Controle.md**  
  Le questionnaire complet, avec réponses cachées pour éviter l’auto‑suggestion.

- **README.md**  
  Ce fichier.

---

# 04 — Méthode d’utilisation

Le testé doit répondre :

- sans aide externe,  
- sans consultation du Corpus,  
- sans correction automatique,  
- avec honnêteté cognitive,  
- en cherchant à exprimer ce qu’il a réellement compris.

Le but est la **vérification**, pas la réussite.

---

# 05 — Structure du questionnaire

Le questionnaire est organisé en trois parties :

- **01‑01 — Connaissance du logiciel CATAR**  
  Concepts fondamentaux, logique du JEu, structure Absolu/Relatif.

- **01‑02 — Compréhension symbologique**  
  Symboles, analogies, représentations zoologiques et mythologiques.

- **01‑03 — Compréhension jeux de mots**  
  Lecture phonétique, double sens, intuition linguistique.

Chaque question possède une réponse unique, permettant une correction simple et objective.
